# オートレース入門（分析する人向け）

競輪を知っている前提で、違うところを中心にまとめる。数字の細部は収集データで裏を取ってから使うこと。

## 競輪との一番の違い

| | 競輪 | オートレース |
|---|---|---|
| 乗り物 | 自転車（人力） | 600ccのオートバイ（エンジンは選手が自分で整備） |
| 勝負を決めるもの | ライン・展開・脚 | **エンジンの調子（試走タイム）** と **ハンデ** |
| スタート | 全員同じ位置 | **ハンデ戦**：強い選手ほど後ろ（0m〜10m刻み）から出る |
| 直前情報 | 並び・コメント | **試走**：レース約30分前に1周全力で走り、タイムが公表される |
| 天候 | 影響は小さめ | **雨（湿走路）で別競技になる**。タイヤも晴用／雨用で変わる |
| 車立て | 7〜9車 | 基本8車（7車もある） |

## 押さえる用語

- **ハンデ**：スタート位置の差。0m線が最前、10m・20m…と後ろへ。実力上位ほど後ろ。
- **試走タイム**：本番前の1周（500m）を100mあたりの秒数に直した値。例 3.39。小さいほど速い。
  目安として「試走0.01秒 ≒ ハンデ10m」と言われる。業界では「オートは試走で7割決まる」とも言われる。
- **競走タイム**：本番の100mあたりの平均タイム。
- **偏差**：最近の良走路での「試走タイムと競走タイムの差」の平均。試走の数字を本番でどれだけ出せる選手かが分かる。
  → 試走タイム + 偏差 ≒ 本番の予測タイム、という使い方ができる。
- **走路状況**：良（乾いている）／湿（濡れている）／斑（まだら、乾きかけ）。湿は巧拙の差が大きい。
- **ランク**：S級・A級・B級＋順位（例 S-12）。半年ごとに見直し。
- **スタート（ST）**：スタートの飛び出し。後ろのハンデから前を抜くにはスタート力が大事。
- **トップ引き**：0mの最内（1番車）。前に誰もいないので逃げやすい。
- **LG（ロッカーグランド）**：所属場。競輪の「地元」に近い。

## 場（5場）

川口（埼玉）・伊勢崎（群馬）・浜松（静岡）・飯塚（福岡）・山陽（山口）。
船橋は2016年に廃止。場によって走路の材質・形・ナイター／ミッドナイトの有無が違うので、場ごとに傾向を分けて見る。

## 賭式

単勝・複勝・2連単・2連複・ワイド・3連単・3連複（＋重勝式のモトロト）。
8車の3連単は 8×7×6 = 336通り。

## 「市場のゆがみ」の候補（検証する仮説）

データが揃ったら、それぞれ「当たる確率 × オッズ」が1を超える領域があるかを検証する。

1. **試走一番時計の過剰人気**：試走が速い選手にお金が集まりすぎて、期待値がマイナスになっていないか。逆に「試走2〜3番手」が割安では？
2. **偏差の見落とし**：試走は遅めでも、偏差が小さい（本番で落ちない）選手は過小評価されていないか。
3. **ハンデ×試走の換算のずれ**：「0.01秒＝10m」の換算が場・走路・ハンデの重さで本当に正しいか。ずれていれば、そこが市場のゆがみ。
4. **走路の変わり目**：湿→斑→良と乾いていく途中のレースは、前日・前走のタイムがあてにならない。市場が追いつかない可能性。
5. **再試走・試走の気温差**：気温・路面温度でエンジンの出方が変わる。昼→夜（ナイター）で試走と本番の差が広がるか。
6. **連日の上がり調子**：エンジン整備がハマった選手は開催中に試走タイムが良くなっていく。前日比の伸びは短期の情報で、競輪で注目していた「短期で変わる要素」と同じ考え方が使える。
7. **最終オッズの締切前の動き**：試走発表後にオッズが動く。発表直後と締切のオッズ差から、プロのお金の向きが読めるか。

## 集めるべきデータ（優先順）

1. 出走表：選手・ハンデ・ランク・LG・期・年齢・車名
2. **試走タイム**（再試走の有無も）・偏差
3. 結果：着順・競走タイム・ST・事故（落車・失格）
4. 走路状況・天候・気温・**走路温度**
5. 払戻金・**確定オッズ（全賭式）**
6. 予想印・コメント（オッズパークの予想情報。過去分も残っている）
