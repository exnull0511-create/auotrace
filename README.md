# オートレース分析システム

過去レースを集めて、**オッズに対して割安な買い目**（市場のゆがみ）を探す。
競輪攻略（[keirinbusines](https://github.com/exnull0511-create/keirinbusines)）と同じ作り。

オートレースの基本と、検証する仮説は [docs/autorace_primer.md](docs/autorace_primer.md)。

## データ

取得元は公式 autorace.jp の内部API（ブラウザが裏で呼んでいるJSON）。HTMLを読むより壊れにくい。
`data` ブランチに `races/YYYY/YYYY-MM-DD.jsonl.gz`（1行=1レース）で溜まる。1レースに入っているもの:

| 項目 | 中身 |
|---|---|
| `entries` | 車番・選手・LG・期・年齢・ランク・**ハンデ**・**試走タイム**・再試走・**偏差**・2連/3連対率・90日成績（ST平均・良走路の平均試走/競走タイム）・180日の良/湿走路連対率・通算勝率 |
| `cond` | 天候・気温・湿度・**走路温度**・**走路状況（良/湿/斑）**。試走時点と発走時点の2つ |
| `result` | 着順・**競走タイム**・試走タイム・**ST**・事故/反則 |
| `laps` | **周回ごとの順位**（何周目で誰が抜いたか） |
| `refund` | 全賭式の払戻・人気・的中票数 |
| `odds` | **全賭式の確定オッズ**（3連単336通りなど）・発売票数。払戻と照合済み（`odds_check`） |
| `expect` | 公式の予想（晴/雨）と公式AI予想の買い目 |

確認済み: 2018年のレースでも出走表・確定オッズまで全部取れる。結果・払戻は2014年まで遡れる。

## 自動実行（GitHub Actions）

| ワークフロー | 内容 |
|---|---|
| `collect-daily` | 毎日 0:40 に直近3日分を取得。日付を指定して手動実行も可 |
| `backfill-history` | 6時間ごとに過去分を新しい順に遡って取得（既定は2018年まで）。残りがあれば自分で次を起動 |
| `probe-site-structure` | サイト構造の調査用（普段は使わない） |

## 分析

```
python -m ai.explore --data data [--since 2024-01-01] [--place 川口] [--track 良]
```
人気順・試走順位・予測順位（試走+偏差とハンデから出した本番の予想順）・ハンデごとに、
実際の1着率と市場の1着確率の差、単勝回収率を並べる。

## 進め方

1. ~~サイト構造の調査~~
2. ~~収集プログラム~~
3. 過去分のバックフィル（進行中）
4. 仮説の検証：試走順位・偏差・ハンデ換算・走路の変わり目 × 人気 × 回収率
5. 買い目の採点（自分で組んだフォーメーションを割安/割高で判定）
6. 締切前オッズの時系列（試走発表の前後でどう動くか）
